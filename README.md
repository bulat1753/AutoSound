# Street Scream

Внутренняя система студии автозвука. Адаптивный интерфейс для компьютера и телефона: заказы, услуги, сотрудники, фотографии, календарь и финансы.

Технологии: React, TypeScript, Vite, Cloudflare Workers, D1 и R2. Рабочие данные хранятся на сервере. Пароли сохраняются как PBKDF2-хеши с индивидуальной случайной солью.

## Запуск на компьютере

Требуется Node.js 22.13 или новее.

```powershell
npm ci
```

Скопируйте `.dev.vars.example` в `.dev.vars`, задайте случайный длинный `BOOTSTRAP_TOKEN` и выполните:

```powershell
npm run db:migrate:local
npm run dev
```

Откройте адрес из вывода команды. Для настройки первого владельца используйте `/?setup=ВАШ_BOOTSTRAP_TOKEN`. После создания владельца новых сотрудников добавляют из его аккаунта. Самостоятельной регистрации нет.

Локальная база отделена от рабочей облачной базы. Реальные ключи и пароли нельзя добавлять в исходники или систему контроля версий.

## Почта

Для писем подтверждения и восстановления используются `RESEND_API_KEY`, `MAIL_FROM` и `APP_ORIGIN`. Нужен подтверждённый домен отправителя Resend. Ключ хранится как серверный секрет. Без полного подключения отправка отключена.

Ссылки одноразовые и действуют 30 минут. В письмах нет паролей. После сброса пароля предыдущие сеансы завершаются.

## Расчёты

Все суммы хранятся в копейках. Смена заканчивается в 23:00 по Москве. С полученной оплаты работ 30% начисляется сотруднику, 70% — владельцу. Компоненты и их закупка учитываются отдельно.

## Проверка и сборка

```powershell
npm test
npm run build
```

## Развёртывание

Для самостоятельного размещения создайте базу D1 и хранилище R2 в своём аккаунте Cloudflare. В `wrangler.jsonc` замените локальный идентификатор базы на реальный и укажите своё хранилище. Примените миграции к облачной базе, добавьте секреты среды и выполните `npm run deploy`.

Файл конфигурации содержит только названия ресурсов и локальный идентификатор базы. Действующих API-ключей, пользовательских паролей и данных клиентов в исходниках нет.
